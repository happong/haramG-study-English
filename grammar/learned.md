# Learned Grammar & Expressions

- 기본 현재형: 주어 + 일반동사
- be동사 현재: am / is / are
- be동사 과거: was / were
- 일반동사 과거형: 규칙 변화 및 일부 불규칙 변화
- 현재 / 과거 / 미래(be going to) 시제 구분
- be going to + 동사원형
- want to + 동사원형
- decide to + 동사원형
- because = 이유, so = 결과, but = 대조, and = 연결
- every day vs everyday
- go home / arrive home
- work at + 장소/회사
- worried about + 대상
- get better at English
- after + 문장/시간 표현
- start work / finish work
- prepare + 목적어 / prepare for + 목적
