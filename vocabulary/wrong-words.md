# Wrong Words / Patterns

오답이 발생한 단어와 반복 오류를 누적 관리한다.

## Current focus
- review → reviewed — practice와 의미 구분 및 과거형 집중 복습.
- send → sent — 과거형과 `send + object + to + person` 구조 복습.
- update → updated — `update + person` 구조 복습.
- prepare → prepared — `prepare for + event` 구조 복습.
- materials — 철자 오류(meterials/marterials) 반복.
- sleep → slept — 반복 오류. 철자/과거형 형태 집중 복습.
- arrive → arrived — 과거형 및 arrive home 구조 복습.
- meet → met — 과거형 형태 복습.
- run → ran — 과거형 형태 복습.
- every day vs everyday — 부사구와 형용사 구분.
- yesterday morning / tomorrow morning — last/next morning 대신 자연스러운 표현.
- taxi — 철자 오류(texi) DAY26에서 3회 반복. 집중 복습 필요.
- wait → waited — DAY26에서 신규 학습 직후 과거형 누락(현재형으로 씀). 반복 확인 필요.
- share → shared — 과거형 누락.
- take a break — "쉬다/휴식을 취하다"는 뜻인데 "타는 것을 멈추다"로 오해함. take의 "타다" 뜻과 혼동 주의.
- want → wants — 3인칭 단수 주어 뒤 동사 -s 누락.
- because / so의 이유·결과 관계 — DAY26에서 반복 오답. because 뒤에 결과를, so 뒤에 결과를 놓는 순서를 헷갈림.
- wait for + 목적어 — "wait for to + 목적어"처럼 전치사를 중복 사용함.
- 연결 문장(so/because)에서 두 번째 절의 주어 생략 — "He was late, so took a taxi." 처럼 주어 없이 씀. 영어는 절마다 주어가 필요함을 반복 강조 필요.
- be going to + 동사원형 — "I am going to sent..."처럼 동사원형 대신 과거형을 씀.

## Known recurring patterns
- go home (not go to home)
- arrive home (not arrive to home)
- arrive at + place
- prepare for + event
- update + person
- share + object + with + person
- send + object + to + person
- want to + 동사원형
- decide to + 동사원형
- be going to + 동사원형
- after + 절에서 시제와 주절의 시간 관계 구분
- every day vs everyday
- because / so의 이유·결과 관계
- 일반동사 과거형 vs was/were
- we were (not we was)
- 문항의 시간·장소·대상 등 원래 정보 보존
- 관사(the) 누락 주의: the materials, the meeting, the team
- 시간 표현 앞 전치사 at 누락: finished work at 10:30 p.m.
- wait for + 목적어 (wait for the bus, not wait to the bus)
