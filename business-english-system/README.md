# 업무 문장 기반 영어 학습 시스템

게임 개발·서비스 및 PM 업무에서 사용하는 영어를 학습하기 위한 운영 폴더입니다.

## 구성

- `learning-stage.md`: 학습 단계와 난이도 조절 기준
- `prompt.md`: 업무 문장 분석·문제 출제·채점 운영 프롬프트
- `progress.md`: 학습 진도와 회차별 기록
- `mistakes.md`: 오답 유형별 관리 목록
- `lessons/`: 업무 문장별 학습 자료와 복습 기록

## 운영 원칙

1. 업무 의미를 유지하고 자연스러운 실무 영어로 변환합니다.
2. 새 문법은 명확히 표시하고 쉬운 한국어로 설명합니다.
3. 문제는 힌트 없이 다양한 유형으로 출제합니다.
4. 오답은 다른 문맥과 문장 구조로 재출제합니다.
5. 문법적으로 가능한 표현과 실무상 더 자연스러운 표현을 구분합니다.
