# 학습 단계

| 단계 | 학습 목표 | 출제 방식 |
|---|---|---|
| 1 | 짧은 업무 단문 이해 | 핵심 표현, 단문 번역 |
| 2 | 두 문장 연결 | 접속사, 원인·결과 |
| 3 | 조건·일정 포함 | if, when, by, until 등 |
| 4 | 복합 문장 이해 | 여러 절, 수동태, 보고 표현 |
| 5 | 실무 적용 | 회의 발언, 메신저, 이메일, 보고 |
| 6 | 직접 설명 | 실제 업무 내용을 영어로 작성·말하기 |

## 난이도 조절

- 반복 오답이 발생하면 문장을 짧게 줄이고 동일 표현을 새 문맥에서 연습합니다.
- 충분히 익힌 표현은 긴 문장과 실제 업무 상황에 재적용합니다.
- 자료가 짧으면 문제 수를 억지로 늘리지 않고 문맥 변형으로 복습합니다.
- 새 문법은 `새 문법`으로 표시하고 기존 학습 범위와 구분합니다.
